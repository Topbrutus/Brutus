# Security boundary

- Lecture seule des sources observées.
- Aucun mot de passe, token, clé ou secret dans le dépôt.
- Aucun shell public.
- Aucune commande arbitraire distante.
- Les sorties publiées doivent être des snapshots JSON de télémétrie et de preuve uniquement.
- Toute action destructive ou privilégiée reste hors de ce collecteur.

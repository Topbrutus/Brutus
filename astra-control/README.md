# Astra read-only observer

Objectif: exposer un état de lecture minimal pour les cristaux, le moteur mathématique et les fourmis, sans ouvrir de shell public ni exposer de secret.

Principe: 1 collecteur -> 3 sources -> 1 état -> 1 preuve.

Cette branche sert à intégrer le collecteur après repérage des sources existantes.
